olcOS пускает трафик телефона через ваш собственный сервер внутри обычного видеозвонка. Для сервиса это WebRTC-звонок, для вас — VPN или SOCKS5-прокси.

Возможности

Весь сервер сразу

Несколько комнат склеиваются в один канал: большая загрузка идёт по всем, обрыв одной не рвёт соединение.

Не сдаётся

Обрыв замечается быстро, переподключение идёт, пока вы его не остановите. Остановка только на неустранимых ошибках.

Сервер с телефона

Комнаты, ключи, обновление ядра и приглашения для близких — из приложения, без терминала.

VPN или прокси

VPN на весь телефон или SOCKS5 для отдельных приложений, например Telegram.

Прямой режим

Если видеозвонок не нужен: VLESS + REALITY напрямую к серверу.

Только ваше

Никаких общих серверов и аккаунтов: трафик идёт через сервер, который принадлежит вам.

Свой сервер за одну команду

Debian, Ubuntu, Fedora или CentOS с root-доступом. В конце скрипт покажет QR-код — отсканируйте его в olcOS, и телефон станет владельцем сервера.

curl -fsSL https://raw.githubusercontent.com/olcOS/olcos/main/install.sh | sudo bash
